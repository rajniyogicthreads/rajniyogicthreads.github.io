## Swapping any of them

Overwrite the file, keeping the same name — no code changes needed. Shapes that work best:

- `hero.jpg` — square (it's cropped to a circle)
- service cards, gallery tiles, `instructor.jpg` — landscape 4:3
- `banner.jpg` — wide, around 2400×1000

Resize anything wider than ~2000px before adding it; https://squoosh.app does this free in
the browser and keeps the page fast.

## A note on the stock photos

The five Unsplash images (meditation, private, group, workshop, banner) came with the
soloist template and are free to use commercially under the
[Unsplash licence](https://unsplash.com/license), no attribution required. Replacing them
with your own photos of real classes would make the site noticeably more personal.
